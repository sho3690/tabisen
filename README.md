# 旅箋 TABISEN

行きたい場所を付箋にして、次の連休に貼る。いつ・どこへ行くかが決まる旅の計画ボード。

- 付箋の壁: 思いつくまま、行きたい場所・やりたいことを貼る（色、行きたい度 ★、日数の目安、メモ）。
- いつ行く？: 祝日から次の1年の連休（3日以上）を自動で並べる。有休や週末は自分で足せる。付箋を貼って「これで決定」。
- 決まった旅: 決定した「休み → 行き先」が時系列で並ぶ。文面をコピーして家族や友人に送れる。
- 控え: JSON の書き出し / 読み込み。

## データの置き場所
付箋はブラウザの localStorage（このリポジトリの外、端末の中だけ）に保存されます。通信もアカウントもありません。
機種変更の前に「控え → 控えを書き出す」で JSON を保存してください。

## 開発
ビルド不要。`python3 -m http.server 8794 --bind 127.0.0.1` などで開きます。
計算部分（logic.js: 祝日・連休の計算、状態の遷移）は `npm test`（node --test）で検証します。
