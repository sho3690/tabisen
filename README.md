# 旅箋 TABISEN

行きたい場所を付箋にして、次の連休に貼る。いつ・どこへ行くかが決まる旅の計画ボード。
https://sho3690.github.io/tabisen/

- Ideas: 思いつくまま、行きたい場所・やりたいことを貼る（色、行きたい度 ★、日数の目安、メモ）。
- Holidays: 祝日から次の1年の連休（3日以上）を自動で並べる。好きな日程は「＋ 日付を選ぶ」で足せる。付箋を列に貼れば、それが計画。
- 設定: 同期、控え（JSON の書き出し / 読み込み）、隠した休みを戻す、全部消す。

## データの置き場所
付箋はブラウザの localStorage（このリポジトリの外、端末の中だけ）に保存されます。
機種変更の前に「設定 → 控えを書き出す」で JSON を保存してください。

## 同期（任意）
別の端末でも同じ付箋を見たいときは、自分の GitHub の**非公開**リポジトリ（例: `tabisen-data`）に `data.json` を置いて合わせます（sync.js）。
GitHub の fine-grained personal access token を、対象リポジトリはそのひとつだけ・権限は Contents の Read and write で作り、設定 → 同期 に貼ります。
トークンは端末のブラウザの中にだけ保存され、通信先は api.github.com だけです。付箋ごとの更新時刻で合流するので、両方の端末で変えても新しいほうが残ります。

## 開発
ビルド不要。`python3 -m http.server 8794 --bind 127.0.0.1` などで開きます。
計算部分（logic.js: 祝日・連休の計算、状態の遷移）は `npm test`（node --test）で検証します。
